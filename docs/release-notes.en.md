# Lecture Companion · Preview 2.4

## Changes

Version changes: https://github.com/popovantondev/LectureCompanion/commits/main/

## Compatibility

Windows 11 · x64

## Installation

Download all four parts and JoinPortable.cmd into one folder (about 5.8 GB). Run JoinPortable.cmd to verify and combine them, extract the entire ZIP and open LectureCompanion.exe.

## Limitations

Teams Desktop and compatible drivers; recommended: 32 GB RAM, internal SSD and 25 GB free for the parts, ZIP and extraction. EXE is unsigned; a second clean-PC check is pending.
