## Архитектура

Teams UI Automation → LiveSource (новая речь отдельно от старого контекста) → локальный координатор → OpenVINO → история из десяти ответов → окна помощника.
Кнопка презентации делает свежий PrintWindow-захват демонстрации и передаёт его локальной Ollama. Кэш учитывает хеш картинки и язык; время свежего захвата сохраняется.

Только loopback: 8765 — координатор, 8766 — текст, 11435 — зрение. Изменяющие запросы проверяют Origin и размер входных данных. Субтитры и скрины — недоверенные данные, не команды. Облака и API-ключей нет. Запускатель завершает только свои процессы. Переносимая версия при занятых портах сообщает ошибку, а не использует чужую установленную среду. Вопрос имеет приоритет перед следующим автоитогом, но не прерывает текущую генерацию.

## Сборка

portable.json задаёт относительные пути. Laufzeit/python — самостоятельный Python, не скопированная venv. Явные пути импорта исключают скрытую зависимость от другого Python. runtime_boot.py добавляет каталог приложения. Modelle содержит нужную OpenVINO-модель и только манифест/блоки модели зрения. Личные данные и кэши в архив не входят; Daten создаётся на компьютере получателя.

При отсутствии работающего NPU последовательные ограниченные тесты выбирают CPU/GPU. Изменение устройства, драйвера или модели сбрасывает результат. CPU ограничен четырьмя потоками инференса. Короткий тест не обещает одинаковую скорость на всех задачах.

Разработчику (не пользователю полного ZIP) нужны Python 3.12 и Node.js:
1. `python -m pip install -r requirements-ui.txt`
2. `python verify.py --node PATH_TO_NODE --ui`
3. `python build-exe.py --output BUILD/dist`
4. Подготовить самостоятельную базу Python и пакеты requirements-npu.txt. `prepare-runtime.py --help` показывает параметры локальных компонентов. Скрипт ничего не скачивает и проверяет изолированный импорт.
5. Подготовить [OpenVINO Qwen3-8B](https://huggingface.co/OpenVINO/Qwen3-8B-int4-cw-ov) и [qwen3-vl:2b-instruct](https://ollama.com/library/qwen3-vl:2b-instruct).
6. `python build-portable.py --app APP_FOLDER --runtime RUNTIME_FOLDER --models MODEL_ROOT --output NEW_NAME.zip`. В MODEL_ROOT нужны Qwen3-8B-int4-cw-ov, ollama/manifests и ollama/blobs.
7. Распаковать в другой путь и проверить демо, запуск, языки, вопросы, ошибки слайдов и завершение процессов. Затем проверить на чистом втором Windows-ПК.
8. `python export-source.py --output NEW_SOURCE.zip` создаёт отдельный архив исходников по белому списку для Git.

Зафиксированы Python 3.12.14, Node 24.19.0, OpenVINO 2026.3.1 / GenAI и Tokenizers 2026.3.1.0, NumPy 2.5.3, Ollama 0.33.3. Вес моделей не включается в Git.

## Качество и выпуск

verify.py проверяет синтаксис, единство версии, переводы, белый список, свежесть речи, очередь, режимы, языковой кэш и имитацию выбора устройств. --ui добавляет настоящие окна Windows, стопку, порядок окон, ввод, анимацию и звук с подменённым аудиовыводом. Аппаратные проверки отдельно: CI не должен незаметно читать встречу или загружать модели.

Исправление сопровождается регрессионной проверкой; изменения интерфейса — просмотром синтетических кадров. Реальные лекции не используются как тестовые данные. Версия берётся из version.json. Старые релизы сохраняются. Подпись EXE, тест на чистом втором ПК, выбор лицензии собственного кода и публикация — отдельные этапы. Лицензии зависимостей и происхождение графики сохраняются. Ничего в удалённый Git не отправлялось.
