## Демо без команд

Полностью распакуй ZIP и дважды нажми LectureCompanionDemo.exe. Подпапки оставь рядом. Откроются только вымышленные примеры, без Teams и запуска моделей. Для обычной работы запускай LectureCompanion.exe. В контекстном меню выбери DE, если ранее сохранён другой язык.

- 0:00–0:40: объясни проблему пользователя и отличие новой речи от старого контекста.
- 0:40–1:40: перетащи робота, полистай карточки, наведи на поле вопроса, покажи звук и язык. Скажи, что данные вымышленные, а запросы в демо отключены.
- 1:40–2:40: объясни локальные модели и два раздела ответа: язык лекции, затем язык интерфейса. Одинаковые языки не дублируются.
- 2:40–3:30: открой README и отчёт проверок; расскажи о тестах свежести, очереди и отсутствующих файлов.
- 3:30–4:00: обозначь ограничения Windows и возможные ошибки ИИ. Пользователь исключил второй ПК и длительный тест лекции из текущего завершения; эти проверки не объявляются пройденными.

Полный немецкий текст выступления: PORTFOLIO.de.md.

## Граница завершения

Падение локальной стартовой страницы исправлено и защищено тестом. Публикация репозитория, решение о лицензии собственного кода, при необходимости подпись EXE и создание настоящей истории Git — отдельные шаги. Для macOS сначала нужен сменный адаптер LiveSource, затем собственный захват окна/субтитров с теми же безопасными тестами. Текущая EXE не является готовой Mac-версией.
