Lecture Companion

Begleitet Teams-Vorlesungen: fasst Untertitel lokal zusammen und erklärt eine ausgewählte Folie.

Vorabversion · 2.4 Windows 11 · x64
Herunterladen für Windows Quellcode Python · JavaScript Anleitung ↗

Vor dem StartTeams Desktop und kompatible Treiber; empfohlen: 32 GB RAM, interne SSD und 25 GB freier Platz für Teile, ZIP und Entpacken. EXE nicht signiert; Prüfung auf einem zweiten sauberen PC steht aus.

Alle vier ZIP-Teile und JoinPortable.cmd müssen im selben Ordner liegen. Das Skript prüft Größen und SHA-256. Danach das Archiv auf einer internen SSD entpacken.

Rechtliches: nur mit Zustimmung aller Beteiligten

Die App liest Teams-Liveuntertitel und wertet auf Knopfdruck einen Ausschnitt der Bildschirmfreigabe aus. Holen Sie vorab die Einwilligung aller Beteiligten ein und beachten Sie die Regeln Ihrer Organisation. Das heimliche Aufzeichnen des nichtöffentlich gesprochenen Wortes kann nach § 201 StGB strafbar sein; Meeting-Inhalte können personenbezogene Daten im Sinne der DSGVO enthalten. Was drin steckt

Installation, Funktionen, Datenverbindung und Prüfung.

Installation

Die Schritte aus „In fünf Schritten starten“ und der README (Windows 11 x64).

1. Vier ZIP-Teile und JoinPortable.cmd von der Release-Seite in einen Ordner laden (ca. 5,8 GB)
2. JoinPortable.cmd doppelklicken: prüft Größen und SHA-256, installiert nichts
3. Das erzeugte ZIP vollständig auf eine interne SSD entpacken
4. LectureCompanion.exe starten (der erste Start kann dauern)
5. In Teams die Liveuntertitel einschalten
Ohne Teams ausprobieren: LectureCompanionDemo.exe

Ihre Daten

Untertitel und Folienbilder werden lokal verarbeitet, ohne API-Schlüssel und ohne Cloud-Fallback. Nur Teams und Windows selbst nutzen gegebenenfalls das Internet.
