Lecture Companion

Помогает следить за лекцией в Teams: локально обобщает субтитры и объясняет выбранный слайд.

Предварительная версия · 2.4 Windows 11 · x64
Скачать для Windows Исходный код Python · JavaScript Руководство ↗

Перед запускомTeams Desktop и совместимые драйверы; рекомендуются 32 ГБ RAM, внутренняя SSD и 25 ГБ свободного места для частей, ZIP и распаковки. EXE не подписан; проверка на втором чистом ПК не выполнена.

Все четыре части ZIP и JoinPortable.cmd должны находиться в одной папке. Скрипт проверяет размеры и SHA-256. После сборки распакуйте архив на внутренний SSD.

Правовые замечания: только с согласия всех участников

Приложение читает живые субтитры Teams и по нажатию кнопки анализирует фрагмент демонстрации экрана. Заранее получите согласие всех участников и соблюдайте правила своей организации. Тайная запись непубличной речи может быть уголовно наказуема по § 201 StGB; содержимое встреч может включать персональные данные в смысле DSGVO (GDPR). Согласие и данные →

Установка

Шаги из раздела «Первый запуск» и README (Windows 11 x64).

1. Скачать четыре части ZIP и JoinPortable.cmd со страницы выпуска в одну папку (около 5,8 ГБ)
2. Дважды щёлкнуть JoinPortable.cmd: он проверяет размеры и SHA-256, ничего не устанавливает
3. Распаковать полученный ZIP целиком на внутренний SSD
4. Запустить LectureCompanion.exe (первый запуск может быть долгим)
5. Включить в Teams живые субтитры
Попробовать без Teams: LectureCompanionDemo.exe

Ваши данные

Субтитры и изображения слайдов обрабатываются локально, без ключей API и облачной подстраховки. Интернет при необходимости используют только сами Teams и Windows.

Проверено

  • JoinPortable.cmd проверяет размеры и SHA-256; контрольные суммы (SHA256SUMS) в релизе
  • Проверки без моделей в GitHub Actions (Windows): verify.py
  • Отчёт о проверке с замерами на одном ПК (VERIFICATION.md)
  • Версия 2.4 и журнал изменений
  • Руководство на немецком, английском и русском

Как это работает

  1. Скачать и собрать 4 части
  2. Включить субтитры Teams
  3. Разобрать текст или слайд

Первые шаги

Скачайте четыре части и JoinPortable.cmd в одну папку (всего около 5,8 ГБ). Запустите JoinPortable.cmd для проверки и сборки ZIP, распакуйте целиком и откройте LectureCompanion.exe.
